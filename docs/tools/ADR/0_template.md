# Modèle ADR

Modèle d'ADR en Markdown

```md
# Titre

- Date : AAAA/MM/JJ
- Décision prise par : Product Owner, Développeurs, Architecte, ...

## Contexte

Description rapide du contexte

## Options envisagées

1. Option 1

    - Avantages :

    - Inconvénients :

2. Option 2

    - Avantages :

    - Inconvénients :

etc.

## Décision

Décision comprise et partagée par l'ensemble de l'équipe

## Conséquence

Décrire l'impact sur l'architecture, le code et les pratiques de l'équipe
```
